# 人性化（AI 人性化）：中文 AI 写作去痕技能

一个 Claude Code 技能，用来给 AI 生成的中文做**人性化**改写，去掉"AI 味"，让文字读起来像真人写的、更自然，同时不改动事实。也就是大家常说的 **AI 人性化 / AI 文本人性化 / 去 AI 化 / AI 改写 / 降 AI 味 / 去 AI 痕迹**。

适用于：

- 改写、润色 AI 生成的中文内容
- 审阅文章，揪出 AI 写作痕迹
- 学习辨认中文里常见的 AI 写作套路

和直接翻译英文工具不同，这个技能针对中文重写过：英文里成立、中文里不成立的模式（比如标题首字母大写、弯引号）被替换掉了；中文特有的 AI 味（互联网黑话堆砌、四字成语对仗腔、八股开场、句尾拖尾升华）被补了进来。

## 安装

### 方法一：git clone 到 Claude Code 目录（Claude Code 推荐）

```bash
git clone https://github.com/taoxee/renxinghua.git ~/.claude/skills/renxinghua
```

Claude Code 的个人技能读的是 `~/.claude/skills/`，直接 clone 到这里最稳。

### 方法二：npx 一键安装（跨 agent 通用）

```bash
npx skills add https://github.com/taoxee/renxinghua.git
```

省事，但它是**跨 agent 的通用安装器**，默认装到 `~/.agents/skills/renxinghua/`，不是 Claude Code 的技能目录。如果装完后 Claude Code 的 `/skills` 里看不到，把它复制（或软链）到 `~/.claude/skills/` 即可：

```bash
cp -r ~/.agents/skills/renxinghua ~/.claude/skills/renxinghua
```

### 方法三：手动安装

1. 下载本仓库的 ZIP 或克隆到本地
2. 把整个文件夹复制到 Claude Code 的 skills 目录：
   - **macOS / Linux**：`~/.claude/skills/`
   - **Windows**：`%USERPROFILE%\.claude\skills\`
3. 确认目录结构：

   ```
   ~/.claude/skills/renxinghua/
   ├── SKILL.md
   ├── README.md
   └── references/
       └── style-cards.md
   ```

### 验证

重启或重新加载 skills 后，在对话里说一句需要去 AI 味的请求即可触发。

> 技能的 `name` 用的是 ASCII 的 `renxinghua`（为了兼容安装器和各类工具链，中文 `name` 会导致安装目录变成 `unnamed-skill`）。「人性化」的品牌保留在标题和描述里。触发靠**描述里的中文触发词按语义激活**。你不用敲斜杠命令，直接说"帮我把这段去掉 AI 味"就行。

## 用法

### 直接说

```
帮我把下面这段去掉 AI 味，改得像人写的：

[粘贴你的 AI 生成文本]
```

### 对话里随手用

```
这段读起来太 AI 了，帮我改自然一点：

本次更新作为我们团队锐意创新的有力证明，为用户带来了无缝、直观且强大的全新体验。
```

### 处理文件

```
帮我把 article.md 里的内容人性化一下
```

### 照着你的文风改

```
这是我以前写的两段：[样本]
照这个感觉，改一下下面这段：[待改文本]
```

## 它怎么改

- 事实不变：不新增数字、来源、经历和承诺，不丢信息，不把"大约"改成确定。
- 缺内容就问：套话删完所剩无几时，问你一到三个问题，或列出建议补充的信息。
- 先理结构再改句子：同一件事只说一次，讲完就停。
- 自动识别文体：判断是论文、周报、客服回复、生活记录帖、吐槽、回忆还是营销文案等，再选写法和改写力度，并告诉你判断结果。判断错了可以直接纠正。
- 写法跟着文体走：论文和公告只删套话；周报结论先行；客服回复讲进展和下一步；生活记录帖、见闻、回忆、吐槽分别用平实记录、白描、克制、口语。
- 跟着样本走：给一两段你自己写的东西，句长、用词和标点向它靠拢。
- 该放手就放手：本来就自然的文字原样返回。

## 几个例子

**改写文旅文案**

输入：

> 坐落于皖南风景如画的群山之间，这座古村落现存约四十栋明清老宅，底蕴深厚、美轮美奂，是一处令人叹为观止的宝藏打卡地。

输出：

> 这座古村落在皖南山里，还留着约四十栋明清老宅，风景很好看。

**改写学术摘要**

输入：

> 本研究深入探讨了机器学习在医疗诊断中的关键作用，凸显了其在不断演变的医疗格局中的重要意义。

输出：

> 本研究探讨机器学习在医疗诊断中的作用。
>
> 建议补充：研究的病种、数据来源与规模、主要结果。

**改写公众号段落**

输入：

> 随着人工智能技术的不断发展，在当今数字化浪潮席卷全球的时代背景下，AI 已经深刻改变了我们的工作方式。

输出：

> AI 已经让我们干活的方式变了很多。
>
> 想写得更实在的话，说一件你身边具体变了的事。

## 它能识别的 AI 写作痕迹

技能里整理了 **33 种**中文 AI 写作痕迹，分七类：

**内容（1–6）**：拔高意义/遗产/趋势、过度强调知名度、句尾拖尾升华、宣传广告腔、模糊归因、八股式"挑战与展望"。

**语言与语法（7–12）**：AI 高频词、回避"是"、否定式排比、三段式排比、同义词循环、虚假范围。

**风格（13–18）**：破折号过度、加粗过度、内联标题式列表、表情符号堆砌、中英文混排与标点混乱、书名号与引号滥用。

**交流（19–21）**：对话协作残留、知识截止日期免责、谄媚语气。

**填充与回避（22–24）**：填充短语、过度限定、通用正能量结尾。

**中文特有补充（25–27）**：互联网黑话堆砌、八股开场、四字成语对仗腔堆砌。

**聊天模型口癖（28–31）**："接住你"式共情、表态式开场、工程黑话外溢、故作深刻与自问自答。

**结构（32–33）**：金句收尾、同一件事讲几遍。

完整的"前 → 后"对比示例、文体识别表和交付前检查清单，都在 [`SKILL.md`](./SKILL.md) 里。

## 核心理念

删掉 AI 套路只是第一步。像人写的文字，来自一个知道自己在跟谁说话、想说哪件事的作者。技能负责把话说清楚、保住作者的语气；具体的事实、经历和态度只能来自作者本人。

这个技能的目标是把文字写好，不保证通过任何 AI 检测器。
